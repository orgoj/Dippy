## Lessons Learned

### Technical Lessons:
- Git worktree merge vyžaduje commit hash, ne worktree path
- `-X theirs` strategie je užitečná pro přidání nové funkcionality ale smaže lokální changes
- WebSearch a edit_rules use stejný pattern - obě potřebují: dataclass field, merge/tag/parse functions, match functions, check/handler functions
- PostToolUse JSON output format: `{"hookSpecificOutput": {"hookEventName": "PostToolUse", "additionalContext": "message"}}`

### Process Lessons:
- Cherry-pick z cizího forku je jinný use case než upstream merge - vyžaduje vlastní workflow
- Evidence cherry-picků je kritická - jinak hrozí duplicity
- Před merge seždy podívat na VŠECHNY branch nejen main
- Testovat v worktree PŘED merge do main

### To Remember for CLAUDE.md:
- Cherry-pick tracking: přidat do commit message "Cherry-pick from: <remote>/<commit-hash>"
- Před mergením z cizího forku: `git branch -a` pro seznam VŠECH branch
- `-X theirs` vyžaduje manuální obnovu lokálních features
