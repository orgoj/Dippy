## Design Decisions

1. **Preprocessing approach**: Expand includes in `_load_config_file()` before `parse_config()` rather than modifying the parser
   - **Why**: KISS principle - keeps parsing logic clean and separate
   - **Why**: Allows includes to work with any directive type
   - **Why**: Comment markers (`# included from: path`) aid debugging

2. **Relative path resolution**: Resolve relative paths from the including file's directory, not the main config file
   - **Why**: Matches user expectation (like C `#include` or shell `source`)
   - **Why**: Enables hierarchical config structures
   - **Why**: Makes included files relocatable

3. **Forgiving error handling**: Missing files log warnings and continue, not hard errors
   - **Why**: Matches existing dippy config behavior (invalid directives are skipped)
   - **Why**: Allows optional includes (e.g., `include .dippy-local-*` works even if no files exist)
   - **Why**: Doesn't break config loading due to missing optional files

4. **Circular detection**: Track resolved paths in a set, raise ConfigError on duplicates
   - **Why**: Prevents infinite recursion
   - **Why**: Resolved paths (not strings) handle symlinks correctly

5. **Test isolation with monkeypatch**: Mock `HOME` environment variable in tests
   - **Why**: `Path.expanduser()` uses real home by default
   - **Why**: Prevents accidental modification of user's live `~/.dippy/` config
   - **Why**: Makes tests truly isolated and reproducible

## Code Patterns Used

### Include Directive Implementation Pattern

```python
def _expand_includes(text: str, base_dir: Path, current_file: Path, included_files: set[Path]) -> str:
    """Recursively expand includes with:
    - Circular detection via set of resolved paths
    - Relative resolution from including file's directory
    - Glob pattern expansion with sorted() for determinism
    - Forgiving error handling (warnings, not exceptions for missing files)
    """
    included_files.add(current_file.resolve())

    for line in text.splitlines():
        if is_include_directive(line):
            pattern = extract_pattern(line)
            pattern_path = resolve_relative_to(pattern, base_dir)

            for match in sorted(glob.glob(str(pattern_path))):
                if match in included_files:
                    raise ConfigError("circular")
                content = read_and_expand(match, included_files)
                yield content
```
