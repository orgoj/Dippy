## Design Decisions

### 1. Separate parallel and serial test targets
**Decision**: Create `just test` (serial) and `just test-parallel` (xdist) instead of always using xdist
**Why**: xdist adds "bringing up nodes" output and progress bars that can't be easily suppressed. Serial execution is cleaner for default use, parallel for speed when needed (like in `just check`).

### 2. Use sed filter instead of pure pytest config
**Decision**: Filter progress dots with `sed -u '/^\.*\s*\[\s*[0-9]*%\]/d'` in justfile
**Why**: Research showed pytest has no built-in way to completely suppress progress dots. Even `-qq` and `console_output_style=classic` still output dots. Filtering in the pipeline is the only reliable solution.

### 3. pytest config: `-q --tb=line --color=no`
**Decision**: Use minimal verbosity with line-level tracebacks
**Why**:
- `-q`: Quiet mode (not `-qq` which suppresses too much)
- `--tb=line`: Concise error tracebacks (not `--tb=short`)
- `--color=no`: Cleaner output for logs
- `-p no:sugar`: Disable pytest-sugar if present

## Lessons Learned

### Technical Lessons:
- **pytest quiet mode is limited**: Even `-qq` doesn't suppress all output, especially with xdist
- **pytest-xdist output is separate**: Progress bars come from xdist plugin, not pytest core
- **sed is better than grep for filtering**: `sed '/pattern/d'` deletes lines without affecting exit code
- **Pipeline exit codes matter**: grep returns 1 when no matches, breaking `set -o pipefail`

### Process Lessons:
- **Research BEFORE implementation**: User has limited patience for trial-and-error
- **Web research is required**: When changing unfamiliar configs, search for best practices first
- **Check exit codes immediately**: Test pipeline commands to ensure they don't break on edge cases

## Code Patterns Used

### justfile pipeline pattern:
```bash
command 2>&1 | sed -u '/pattern/d; s/^/[prefix] /' | tee /tmp/log.txt
```
- Merge stderr to stdout
- Filter with sed (unbuffered mode `-u`)
- Prefix output lines
- Log to temp file

### pytest quiet config:
```toml
[tool.pytest.ini_options]
addopts = "--tb=line -q --color=no -p no:sugar"
```
- Minimal verbosity
- Line-level tracebacks
- No color (cleaner logs)
- Disable plugins that add noise
