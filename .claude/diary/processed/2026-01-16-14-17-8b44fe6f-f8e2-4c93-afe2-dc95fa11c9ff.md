## Design Decisions

### Exact word-boundary matching
Initial implementation used substring matching, but user pointed out: "kdyz budu chcit matchovat vice tak prece pouziju glob --force*". Changed to exact word-boundary matching using set intersection.

```python
# Final implementation - exact match only
remaining_words = words[len(prefix_words):]
items_set = set(rule.items)
return bool(items_set.intersection(remaining_words))
```

### Syntax design
- `allow-opt <prefix> <item1> <item2>...` - simple, KISS
- Prefix can be single word or quoted for multi-word (`"git commit"`)
- Items are space-separated, not comma-separated
- Message extraction works same as normal rules (quoted string at end)

### Rule mixing
Option rules mix with normal `allow`/`ask`/`deny` rules in same list, evaluated in order. First match wins.
