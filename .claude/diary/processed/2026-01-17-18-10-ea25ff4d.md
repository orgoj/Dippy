## Task Summary
User requested work on TASK-2: implementing context-aware rules for Dippy's allow/deny/ask directives. The goal was to allow commands like `cd` only in specific contexts (e.g., subshells) while denying them in standalone usage. This prevents AI from accidentally changing the session's working directory.

## Design Decisions
- **AST flags use `@` prefix**: Distinguishes structural context (`@subshell`) from wrapper commands (`ssh`), avoiding collision if a command named "subshell" exists
- **Multiple flags use AND logic**: User pointed out OR can be achieved with multiple rules, but AND cannot otherwise be expressed
- **Wrapper commands without `@` prefix**: `ssh`, `sudo` will be flags without `@` to distinguish from AST context
- **Backward compatible**: Rules without `[flags]` match any context, preserving existing behavior
