## Design Decisions

### Decision 1: Keep parameter order compatible (not keyword-only)
- **Initial approach**: Made `context_flags` keyword-only with `*` in function signature
- **Issue**: Broke all existing callers that passed it positionally
- **Solution**: Changed to regular parameter before `*`, keeping backward compatibility
- **Reason**: Easier to update function signatures than all call sites

### Decision 2: Add sh -c / bash -c delegation in analyzer
- **Context**: Docker handler delegates to `sh -c 'script'` but there was no sh/bash handler
- **Options**: Create handler modules OR add special handling in analyzer
- **Choice**: Added special handling in `_analyze_simple_command()` (lines 612-619)
- **Reason**: Simpler, avoids creating new handler files for built-in shell commands
- **Implementation**: Extract script from tokens[2], strip quotes, delegate to `analyze()`

### Decision 3: Skip cd commands when remote=True
- **Context**: In containers/ssh, `cd` commands should be allowed (they don't affect host)
- **Implementation**: Added check in list handling (lines 108-123) to skip cd when remote
- **Reason**: We don't track path changes in remote mode, so cd is a no-op for security
- **Code**: Check if node kind is "command" and base is "cd", skip analysis if remote=True

### Decision 4: Paths not expanded when remote=True
- **Context**: Container commands like `docker exec nginx cat ./foo` should NOT expand `./foo` to host path
- **Implementation**: Modified `_match_words()` to check `remote` flag and use literal words instead of normalized paths
- **Reason**: In containers, paths refer to container filesystem, not host filesystem
- **Code**: `normalized_cmd = " ".join(words) if remote else _normalize_words(words, cwd)`

### Decision 5: Fix test patterns instead of code
- **Issue**: Tests used patterns like `Rule("allow", "python")` which only matches exactly `python`, not `python script.py`
- **Root cause**: fnmatch pattern matching requires wildcards for partial matches
- **Solution**: Changed patterns to `python *`, `make *`, `rm *`, etc.
- **Reason**: Tests were incorrectly written, not code bugs. This is the correct fix.

## Lessons Learned

### Technical Lessons:

1. **Python parameter ordering**: Making a parameter keyword-only breaks all positional callers
   - Use keyword-only parameters carefully, only for truly optional parameters
   - Consider backward compatibility when changing function signatures

2. **fnmatch pattern matching**: Requires explicit wildcards for partial matching
   - `python` ≠ `python *`
   - Pattern matching is exact unless wildcards are used
   - Always test pattern matching behavior

3. **Remote mode isolation**: Commands in containers/ssh should not access host paths
   - Path normalization should be skipped when `remote=True`
   - Literal paths should be used instead of expanded absolute paths

4. **Context flags propagation**: All recursive analysis must pass context_flags through
   - `_analyze_node()` → `_analyze_command()` → handler delegation → inner command analysis
   - Missing even one link breaks the chain
