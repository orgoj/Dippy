## Design Decisions
- **Pattern-starts-with-base check**: When config pattern already includes command name (e.g., `mkdir -p ./**`), don't prefix with base again - just show the pattern directly
- **Context flags in list/pipeline**: Added `context_flags=list_flags` and `context_flags=pipeline_flags` to Decision objects in allow path, ensuring flags are logged
- **Merge strategy**: Used merge (not cherry-pick) to avoid duplicate commits when syncing branches
