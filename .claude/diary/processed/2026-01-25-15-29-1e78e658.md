### Key Findings

**Critical Issue #1 - Wrapper Context Propagation:**
When CLI handlers return `Classification` with `wrapper_context`, the analyzer doesn't propagate these flags to inner command analysis in `src/dippy/core/analyzer.py:567-572`.

**Critical Issue #2 - Heredoc Missing Parameter:**
`_analyze_redirects()` and `_analyze_string_cmdsubs()` missing `context_flags` parameter, causing NameError in heredoc tests.

**Critical Issue #3 - MCP/WebSearch Test Fixtures:**
Tests fail with `SystemExit: 2` because `dippy.py:parse_cli_args()` called during module import but pytest's sys.argv contains test paths.

**Issue #4 - Reason Formatting:**
Analyzer produces redundant `"echo (echo *)"` instead of `"echo *"` due to pattern formatting logic.

**Issue #5 - Config Pattern Bugs:**
Tests used `Rule("allow", "python")` instead of `Rule("allow", "python *")` - patterns need wildcards to match commands with arguments.

## Lessons Learned

### Technical Lessons:
- **HandlerContext pattern**: Upstream introduced `Classification` with `wrapper_context` field, but analyzer wasn't propagating these flags to inner commands
- **Module-level side effects**: `dippy.py` calls `parse_cli_args()` at module import time (line 500), which breaks pytest unless sys.argv is mocked
- **Config pattern syntax**: Rules need `*` wildcard to match commands with arguments (e.g., `python *` not `python`)
- **Remote mode feature**: Docker/kubectl handlers have `remote=True` parameter to prevent path expansion against host cwd

### Process Lessons:
- **Explore agent effectiveness**: Using Explore agent for systematic test failure analysis identified root causes across 56 tests much faster than manual investigation
- **Categorization matters**: Grouping failures by category (systematic vs isolated) helps identify which fixes will resolve multiple tests
- **Plan before implementation**: Multi-phase implementation plan prevents breaking things that are already working

## Code Patterns Used

### Wrapper Context Propagation Pattern:
```python
# WRONG - doesn't propagate wrapper_context
inner_decision = analyze(result.inner_command, config, cwd, remote=result.remote)

# CORRECT - combines context_flags with wrapper_context
inner_flags = context_flags
if result.wrapper_context:
    inner_flags = context_flags | frozenset(result.wrapper_context)
inner_decision = analyze(result.inner_command, config, cwd, context_flags=inner_flags, remote=result.remote)
```
