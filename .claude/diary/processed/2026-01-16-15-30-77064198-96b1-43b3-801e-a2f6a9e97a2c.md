## Design Decisions
- **Pass returns empty dict `{}`**: This signals to Claude that the hook didn't handle this tool use, so Claude falls back to its default permission system
- **Priority: deny > ask > allow > pass**: Most restrictive wins; pass is only used when nothing else matches
- **config.default controls fallback**: When no rule matches, check config.default before running analyzer logic
- **No "pass*" config rules**: Pass is only available as a default setting, not as a pattern rule (keep it simple)

## Code Patterns Used

**Pass action implementation pattern:**
```python
# In Decision dataclass
action: Literal["allow", "ask", "deny", "pass"]

# In _combine() - collect all decision types
pass_reasons = [d.reason for d in decisions if d.action == "pass"]
# Return pass if all are pass (lowest priority)
return Decision("pass", ", ".join(pass_reasons), children=decisions)

# In dippy.py - empty response = no hook intervention
def pass_(reason: str = "passing through") -> dict:
    logging.info(f"PASS: {reason}")
    return {}
```
