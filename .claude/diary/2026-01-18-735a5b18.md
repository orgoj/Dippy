## Lessons Learned

### Technical Lessons:
- Dippy configuration `allow [] [[] *` enables both `[ ]` and `[[ ]]` test constructs
- The syntax works with:
  - POSIX single brackets: `[ -f file ]`
  - Bash double brackets: `[[ condition1 && condition2 ]]`
  - In `if` statements: `if [ ]; then ... fi`
  - Complex conditions with operators: `-f`, `-d`, `-r`, `-eq`, `==`, `&&`, `||`, `!`

### Process Lessons:
- Dippy documentation should focus on Dippy configuration, not on teaching bash
- Keep reference docs minimal - users reading config docs already know bash
- When user says "kurva" repeatedly, pay attention - they're correcting fundamental misunderstandings
