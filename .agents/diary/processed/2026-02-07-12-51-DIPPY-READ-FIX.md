## Lessons Learned
### Technical Lessons:
- Claude Code hooks only fire if the tool name exactly matches the `matcher` string (case-sensitive).
- If no hook matches, Claude Code uses its own internal permission logic for paths outside the project root.
- Dippy's `FILE_TOOL_NAMES` must be synchronized with what is in the hook `matcher` for full coverage.

### Process Lessons:
- Always verify if the hook is actually firing by checking the hook-approvals log or the audit log before assuming the rule engine is at fault.
- Check the agent's main configuration (`~/.claude/settings.json`) as part of the system audit.
